# 账户与注册管理

管理入口为同源 `/admin`，使用独立管理员密码和两小时 HttpOnly 会话。管理API契约见 `openapi-admin-v2.2.json`。

管理员可开放或停止新账号注册；设置保存在账号数据库中，重启后保持。关闭注册不影响已有账号登录、改昵称和改密码。

账户列表支持按数字UID或昵称搜索。管理员可以修改昵称、清除头像、注销会话、停用/启用账号、直接设置8–16位新密码，以及永久删除符合条件的账号。密码只进入哈希队列，不在响应和审计日志回显。

永久删除只允许账号没有关联进行中对局时执行；死亡、离线、暂离玩家和未退出的观众都算仍有关联。大厅和复盘阶段可以删除，服务端会先移除当前成员关系并处理房主继任或终局关闭。完成对局保留UID、当局昵称和行动记录，头像回退默认。UID不回收。

停用可恢复，永久删除不可恢复。两者都会撤销登录和媒体授权；正在进行的玩家只能停用为离线席位，不能删除。
