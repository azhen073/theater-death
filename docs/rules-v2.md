# 规则 2.0 增补

来源：用户2026-09-18批准的后端迭代计划，优先于1.1中被覆盖条款。仅version=2.0生效；默认人数、阵营胜负定义和技能未改。

- V2-01（覆盖R41/R45相关顺序）：晨间/放逐结算完成翻牌、阶段转换与回归效果后即查胜负。成立则立即game_ended，跳过遗言、天理移交和后续窗口；非终局继续正常流程。
- 保留R51：死亡事件锁定转阶段，不能因同晨回归撤销；门先生满足条件的阶段回归先于胜负检查。
- V2-02（覆盖R41/R42首日顺序）：首夜入夜存活名单保存在night.eligibleAtStart；首夜技能完成后先进行竞选，再执行完整晨间公告及结算。实际夜间死亡者仍可报名/发言/投票/当选，公告前不冻结其白天公共权限。晨间若终局立即结束，否则首夜遗言、必要的天理移交、普通发言；不重复竞选。
- V2-03：普通/竞选发言120秒，先有15秒准备窗口（不开麦），本人可START_SPEECH提前开始，超时自动开始。个人技能及回归30秒，阵营60秒，指定发言顺序独立45秒；遗言60秒、平票发言45秒、投票60秒、移交45秒、报名30秒不变。
- V2-04（覆盖R47）：截止时优先最新全员确认方案；若从未全员确认，使用服务端最后接受的合法草稿（含空刀），不要求额外确认；无草稿为空刀。魂灵和二阶段联合池都采用此规则。客户端时间戳不决定先后。

其余已批准变更及逐步实现状态见 docs/backend-v2-plan.md 与 docs/backend-v2-progress.md；未实现步骤不能据此声称已交付。
