# 舞台行动与座位呈现

## 身份揭示

正式玩家每局首次进入对局时显示一次身份卡，内容来自 `private.self` 和角色目录。公共观战、私人第二屏与复盘不自动显示。`sessionStorage` 按房间、对局和玩家去重；有效行动剩余不超过 10 秒或计时不可靠时，行动优先且不补播。

## 行动交互

- 所有行动、目标选择、参数调整、提交与恢复都在舞台内完成，不提供第二个提交入口。
- 合法意图只需一次最终确认；清空本地选择不会发送请求。
- 团队方案使用单按钮：未修改方案时确认当前版本，修改后发布并确认本人，本地目标为空时发布空刀。
- 队友仍需分别确认，截止时的生效规则由服务端决定。
- 点击座位切换目标，`maxTargets` 表示不同目标数上限；界面不提供同一目标重复刀数。
- 我的选择使用浅蓝实线，当前草稿目标使用浅青虚线；重合时保留两类提示，并有文字和无障碍标签。
- 空队伍目标统一称“空刀”，本地空目标才称“空选择”。

提交证据按账号、房间、对局、成员和视角隔离。网络冲突时不能同时把旧快照和新回执都当成事实，允许恢复同步或重新提交合法意图。发言顺序预览通过 `POST /rooms/{code}/speech-order-preview` 获取，UI 不再自行计算座位顺序。

## 死亡呈现

公开死讯可触发最长 3.2 秒的座位粒子和文字公告；已公开死亡头像保留静态星芒。私有濒死和未公开死讯不触发公共效果。

刷新、重连和首次加载只建立事件游标，不重播历史。减少动画时保留静态标记和公告，关闭死亡特效时仍保留死亡文字。画布不接收指针事件，并在到期、隐藏或卸载时释放资源。

## 夜间舞台层次

夜间布景由剧场遮罩、顶部聚光、暗角和每轮至多播放一次的雾与微尘组成，不读取私有窗口或行动进度。减少动画时停用雾、微尘和聚光摆动，保留静态层次；舞台亮度继续作用于全部氛围层。座位光晕沿用选中、草稿和发言状态色，死亡座位熄灭。

暗色主题区分昼间冷灰蓝与夜间近黑布景；死亡星芒使用同源键控素材和普通混合，避免白底素材在暗色背景中消失。

## 座位徽标

徽标位于座位号行内，顺序为身份、天理、魂灵、查验结果。2/3/4 字徽标统一使用 7px 字号和 35×12px 盒，不改变座位卡高度。

| 类型 | 数据来源 |
| --- | --- |
| 身份 | 仅本人或授权第二屏的私有身份 |
| 天理 | 公开天理座位 |
| 魂灵 | `private.knowledge.spiritSeats` |
| 查验结果 | 本人 `descender_check_result` 事件 |

降临者一阶段查验显示“魂灵 / 非魂灵”，二阶段显示“死神阵营 / 人类阵营”。同一座位只保留最近一次查验，先比较夜数，同夜取后发生的事件。本人已查座位避免重复展示会造成拥挤的身份徽标。

濒死标记位于座位左下角，只读取按权限出现的 `private.knowledge.dyingSeats`，不改变公开 `alive`。

## 响应式布局

- 601–900px 竖屏使用双排浅弧布局；超出适用范围时回退网格。
- 320px 档使用两列网格，保证号码与徽标同排。
- 移动端情报页签位于底部，不复制面板 DOM，也不主动抢走聊天或事件滚动位置。
- ≤680px 下滑超过 120px 时 HUD 收起，回到 24px 以内展开；操作进入“更多”面板，桌面不收起。
- ≤680px 的当前目标摘要和原有提交按钮组成紧凑行动条，固定在底部情报页签上方并预留安全区；选座后无需回滚页面即可提交。桌面保持舞台内布局，不复制提交入口。
- ≥901px 的大厅长成员列表独立滚动，规则侧栏吸附且不越出视口；移动端恢复自然列表。座位详情保留头像和完整状态，长昵称、UID 可换行且不产生横向溢出。
- 复盘提供座位环形图、身份卡、轮次锚点、票型和死亡事件呈现。

相关测试以 `tests/frontend-v2-*` 和 `e2e/specs-v2/` 中行动、布局、徽标、死亡和复盘套件为准。
