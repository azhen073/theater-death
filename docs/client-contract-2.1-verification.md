# 契约 2.1 验收映射

来源：工作区 `Client Requirements(v2)/剧院死神_前端需求规格_v2.md` 与用户批准的对齐计划。此表描述必须验证的行为；只有进度记录中的真实执行结果可作为通过证据。

| 前端需求 | 服务端交付 | 关键否定场景 |
| --- | --- | --- |
| AUTH-01 | 邀请预检、注册、一次消费 | 预检后撤销/竞争消费仍禁止注册；响应未知使用登录 |
| AUTH-02 / GLOBAL-01 | 会话恢复、本人当前房间/原局恢复列表 | 登录不自动接管；其他账号不可见 |
| ACCOUNT-01 | 只读账号名、默认头像null、上传/下载/资料版本 | 错类型、动画、过量像素、写失败保留旧图 |
| ACCOUNT-02 | 修改密码全部会话撤销、控制设备注销离开 | 旁路设备注销不移除房间成员；过期仅离线 |
| ROOM-01 | catalog/default13/实验配置、创建后冻结 | playerCount与角色不一致、非法重复、旧昵称要求 |
| ROOM-02 | 单房间原子进入/本人恢复/显式接管 | 并发跨房进入、原玩家伪装公开观众 |
| ROOM-03 | 完整成员、头像、准备、presence、host、config | lobby无角色/座位泄漏，离线≠死亡 |
| ROOM-04 | 满员且全部准备，房主发起 | 观众不计人数；不增加全员在线门槛 |
| ROOM-05 | 手动转移、自动继任、踢出/解散权限 | 观众不能接任；旧房主无权；局中不能主动解散 |
| ROOM-06 | 观众显式补位、零正式成员5分钟回收 | 失败不丢观战身份；观众不能延长；中止不判阵营胜 |
| ROOM-07 / POST-02 | 同房间连续两局、结束复盘 | 清准备、旧gameId/window拒绝、第二屏不跨局 |
| GAME-01/02/03 | 公开HUD/座位、授权任务、并行窗口、倒计时 | 真实死亡公告前不泄漏，不能暴露私有技能窗口 |
| GAME-04 | 动作参数/目标/配额/提交状态/回执查询 | 重放不执行、不同内容同ID拒绝、查询不改变状态 |
| GAME-05 | 公屏与阵营聊天稳定ID/确认 | 旧会话/观众不可发、同ID载荷冲突、无全局序号 |
| GAME-06/07 | 个人情报、独立事件游标、公开投票结果 | 不能提前公开未结算票型或隐藏事件数量 |
| GAME-08 | 完整2.0规则章节+角色说明 | 1.1已覆盖条款不作为现行规则展示 |
| GAME-09 | 明确viewer类型、受控第二屏 | 原玩家退出不能看别人、撤销后不再推私有数据 |
| POST-01 | 结局、时长、角色/座位快照、当前头像与完整复盘 | 非终局无全量信息；仅当前复盘可读 |
| UX-03 | 按账号房间的viewVersion、control原因、跨局订阅 | 旧异步响应不能覆盖新局；未授权变化不增版本 |

发布要求另见实施计划：Docker源码只读挂载、Node原生兼容、账号迁移副本、一次候选全量单元/API门禁、五分钟50连接容量、可验证镜像摘要和数据库配套回滚。真实语音及前端UI不在本次完成声明内。
