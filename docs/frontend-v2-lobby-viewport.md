# 房间大厅视口适配

## 当前行为

- 房间大厅使用 `home-layout--lobby`，取消固定内容宽度上限。
- 横向留白使用 `clamp(20px, 3vw, 64px)`。
- 页面最小高度按 `100svh / --display-scale` 补偿账户显示缩放。
- 内容超出视口时正常滚动，账户页和规则弹窗保留各自阅读宽度。
- 布局只依据当前浏览器视口，不读取显示器尺寸、屏幕坐标或固定 DPR，也不缓存初始窗口大小。

该适配只影响大厅布局，不改变房间状态、会话、接管或玩法。相关浏览器验收为 `e2e/specs-v2/26-lobby-viewport.spec.ts`。真实物理双屏和混合 DPI 行为仍需在对应硬件上确认，不能由视口模拟代替。
